# Light Native v0.5.1 实施合同

批准基准见[原包与双HTML](../design/reference/2026-10-25-light-native-v0.5.1/DESIGN_REFERENCE.md)。2026-10-25用户明确要求执行正式开发、测试及发布。本轮优先于早期暖白/橄榄浅色视觉，仅限呈现和真实状态文案；不批准重排信息架构。

## 呈现与数据边界

五个Tab名称、顺序、功能、日期/编辑流程和真实模块不变；管理中心四分区+独立习惯、13真实目的地、75px分区/38px字标和同原生dialog栈不回退。真实服务、完整字段、来源/日期/未知语义与不可逆确认优先于演示HTML。原型侧栏、虚构数字、演示保存及状态开关不进入生产。

浅色以冷珍珠白/浅蓝灰、深蓝灰正文、克制钴蓝动作、极轻边界/静态投影为准。lightNative.css只在现有effective light生效；旧dark token/偏好、system跟随、设备配置和主题切换仍保留，不新建深色设计。蛋白质/碳水/脂肪、饮水、体重、力量/有氧/凯格尔、危险、日历/报告事实色仍各有意义。light主题浏览器/manifest颜色一致，manifest id/start_url/scope和存储身份不改。

参考主按钮白字对比不足AA，正式同向蓝#286bdd白字4.96:1；次级#2868c9在#eef4ff为4.86:1。文本不为塞进一行而缩小，输入>=16px、目标>=44px。原生Sheet框架及真实管理器字段保留，与原型演示表单的差异明确记录，不声称整屏像素相同。

## 文案与语义块

[文案审核表](LIGHT_NATIVE_V051_COPY_AUDIT.md)按真实数据/状态解释显隐。去掉Today鼓励副句、Progress励志副句、管理冗长介绍；力量/有氧入门说明仅在所选日期确无该类记录时显示。凯格尔方案仍在真实摘要中显示，只去掉重复的第二处方案标题；呼吸/不适安全提示保留。餐次为空时简洁“今日/当日未记录”，不重复日期/餐次标题。

趋势可见说明保留缺测/未知语义，手势教学留在辅助技术文案和原有可访问控件里；统计窗口、覆盖数量、专业限定和报告风险不删。不能以全局display:none隐藏所有备注/说明。来源、AI隐私、粗估不计入实际摄入、计划不等于事实、删除/恢复/手动Sync确认都保留。

长标签、日期、周期/习惯/动作名称在自己的列内安全换行；短菜单不出现最后一字孤行；数值与单位作为完整块，空间不足时整块另起一行。Today水按钮继续靠右、与同级四字动作同尺寸；放大字体时可让完整统计块与右侧按钮分行，二维不重叠，不能裁切数字来保持强制单行。原有折叠餐次最多三名称摘要和特殊饮食预览不冒充完整记录；展开/详情/编辑仍显示全部真实条目和原文。

## Sheet 生命周期与动效

复用sheetController、managementWorkspace、animateMotion和现有唯一VisualViewport/滚动锁。普通Sheet28px/240ms，重用200ms基础token加40ms；训练入口保持58px/275ms、原有执行/计时/Autosave不改。Back只切内层节点并恢复真实父级；X整体关闭。

关闭、业务dispose、源验证、save flush、原生close通知和解除锁仍同步且exactly once。仅追加一个无内容、无控件、无ID、inert/aria-hidden的合成外壳作短退场；不克隆原dialog，不复制凭证、语音、图片、健康表单或用户文本。正常animationend移除，350ms兜底；新Sheet、pagehide和reduce变化立即清理。原生Escape若没有预关闭几何即刻关闭；消费cancel后主动close的现有子视图仍遵循其原业务返回逻辑。

减少动态时不增加位移和退场层。保留键盘/IME/Safe Area与嵌套危险确认合同，不增加私有视口监听、持续测量、第二套弹窗/导航控制器或依赖。

## 版本与发布

fitlog-lite-db、Dexie13/IDB130/22表、Backup14/Restore1–14、Sync/envelope1不变；没有迁移、清库、历史重算、自动同步或个人数据操作。外观服务仅浅色theme-color字符串变更，保存/事件语义逐字保留。manifest仅主题/背景颜色变化，PWA身份不变。

保留全部44旧浏览器门槛、14适用补充、1143单测及管理专项；新增真实五Tab多状态/字体/运动偏好、文字坐标及普通Sheet隐私/生命周期检查。仅按新批准视觉更新必要展示断言，全部业务/事务/权限断言保留，原失败和复跑分开。实际结果与覆盖范围见后续QA和LATEST/十项回执，不由本合同预先宣称通过。

Application正常非强推main→CI/Pages→真实资源/App/active SW/离线/同一合成profile→LATEST-only END→第二次CI/生产/同档案复验。实体iPhone、原安装PWA、真实IME/Safe Area/VoiceOver/个人连续性无证据即Pending，真实Provider与mock分开。旧WebKit饮水Undo−128px未在本轮承诺解决。
