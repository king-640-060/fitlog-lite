# 管理中心 v0.6.1 实施合同

批准基准为[冻结原包](../design/reference/2026-10-24-management-v0.6.1/DESIGN_REFERENCE.md)，2026-10-24 用户明确授权正式实施。仅更新管理中心及其下属真实页面的布局、分组和入口过滤。

- 顶栏“管理与设置”进入“管理中心”。根页使用说明卡、搜索、四个单列分区及个人计划的习惯入口。四分区下的3／2／3／4目的地加习惯，13项完整。分区文字、辅助说明、38px字标及75px行按v0.6.1；没有v0.7封面或五主Tab换肤。浅色复用现有Token，深色仅在管理工作区映射批准的surface／ink／accent值；主操作保留原可读对比，其他页面及临时危险确认的语义色不改。
- 搜索为当前工作区内存草稿，匹配真实名称、说明及分区；可直达真实目的地、清空恢复、无结果明确提示、语义化清空按钮与结果数量。搜索字段不重建、不写localStorage/DB，不持久化用户查询。动态AI/Sync摘要只由原服务提供。
- 复用 `managementWorkspace` 的同一个原生dialog、handle、head、body及路由栈。根→分区→真实管理器→编辑/子页→Back逐层回退；搜索直达的父级就是根页。X任意层退出，关闭后新开从根顶端、空查询开始。不得关闭再打开模拟Back。
- 合法查询、节点与滚动由现有工作区保存；保存继续读取真实服务。未保存的父表单草稿继续由原子视图保留。各领域原有验证、取消提示、确认、空/无结果、加载/错误及资源释放不削弱。
- 实施集中在 `managementHub`、main入口接线、workspace根标题参数和管理专用CSS；真实营养周期编辑器仅给一个长标签包裹静态文本span，保留完整原文与所有绑定，以解决200%字体下的字形溢出；共享native Sheet/VisualViewport、业务服务、数据库、五Tab协调器、训练/Autosave/计时器、Food日期、趋势/日历/报告与危险删除事务不改。
- 生产管理器继续使用六类共享列表/表单，而非原型演示的通用名称/说明表单；66px行／17px圆角、真实字段、Habit52px静态保存、quiet danger及>=44px操作、>=16px输入保留。统一管理框架标题与内边距、安静的新建按钮、带边框表单与批准原型协调。管理CSS严格限制作用域，独立Food/Today入口继续使用相同真实渲染器。
- 保留fitlog-lite-db、Dexie13/IDB130/22表、Backup14/Restore1–14/Sync1/envelope1，以及AI/Voice/WaterReference等设备配置合同。没有迁移、自动同步、重算历史、重置或清空。搜索与导航本身为零业务写入。

执行全部既有44门槛及适用后续目标/份量/饮水/联合交互、v0.4.1导航交接与Restore筛选门槛；新增 `managementV061.mjs` 实测双引擎显示、13真实入口、搜索/Back/X、节点/几何及22表/配置摘要。旧测试仅适配经批准的新入口路径与根标题，原业务、几何、保护断言保留。详见[QA](MANAGEMENT_V061_QA.md)。实体iPhone、原安装PWA、真实IME/Safe Area、VoiceOver和个人数据连续性必须有独立物理证据，未实测标Pending。
