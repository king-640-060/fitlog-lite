## 日期与提交边界

Food 设置/编辑目标始终先打开「设置当日营养目标」。读取选中本地日期的真实模板/方案/阶段/目标；已有目标显示来源和四项快照。可用模板直接可见，新建为一级操作，手动为次级入口；归档模板和无日方案模板解释禁用原因，管理入口保留。有效状态由包含该日期的真实阶段计算，不根据内存选中值或数值相等猜测。发现多阶段覆盖同日时拒绝继续，不选任意一条。

| 状态/操作 | 结果与允许写入 |
| --- | --- |
| 无模板、无阶段、已有手动目标 | 仍先选择器；只读；可新建/手动 |
| 选日期有效的模板 | 到真实日方案；不写入 |
| 选未启用/日期非有效模板 | 显式启用确认，显示起始日和上一阶段结束日；取消零写入 |
| 确认启用 | 原事务结束上一阶段并新增一个阶段；不写每日目标/周期/健康记录 |
| 选日方案 | 到四项目标「已保存/将应用」预览；不写入 |
| 确认应用 | 原事务仅保存选定日期的目标快照、真实strategySelection；其他日期和cycle排程不变 |
| 新建/编辑日方案并保存 | 仅更新内存模板草稿；还须保存整个模板 |
| 保存新模板 | 原事务仅保存模板和日方案；回到选择器；不自动启用/应用 |
| 手动编辑/删除 | 原服务，仅所选日期；事务内核实原目标，陈旧源拒绝；防重复提交 |
| 归档/缺少日方案 | 不可直接应用，可进入原管理流程 |
| 历史/未来日期 | 始终使用选定日期；新启用不允许未来开始、不允许覆盖旧阶段；冲突明确阻止 |

同日更换刚开始的模板，现行服务会因开始日期必须晚于最新阶段开始/结束日而拒绝。v0.2没有授权改写这项历史规则，不能删除旧阶段、缩成空区间或静默替换。未来日目标可使用该日期真实有效的模板；启用本身仍从允许的非未来日期开始，不是周期排程。

## 并发和数据保护

`nutritionGoalPicker.ts`只拥有导航和预览，不存储业务对象。复用`createManagementWorkspace`、`activateNutritionStrategy`、`applyNutritionStrategyVariant`和原手动服务。启用额外可选复核完整阶段/定义指纹，在同一原事务内检查；其他调用保留原API兼容。应用继续核实完整context、variant、当天目标。跨标签变更必须重新查看/确认，不以最后写入胜出。失败保留可重试UI，事务失败完整回滚。

DB仍为fitlog-lite-db / Dexie13 / IDB130 / 22表，Backup14 / Restore1–14 / Sync1 / envelope1不变。没有schema、迁移、parser、周期/报告/删除事务、饮水或训练改动。不清空用户数据库；破坏性失败/恢复测试仅在隔离合成档案。

## Sheet与草稿

选择器到新建/日方案/启用/预览复用同一原生管理Sheet和header，large尺寸由现有viewport/CSS计算。模板编辑进入、子页与返回清除该编辑器的像素冻结；不修改共享`stabilizeSheetSubview`、sheetController或全局滚动。编辑器Save放在所属footer并通过form属性关联真实表单；header/footer稳定、body内部滚动，输入沿用≥16px/触控≥44px。长标题仅在此目标/模板流程自然换行。

日方案返回/ESC和模板返回/X/遮罩都有未保存确认，取消确认保留原草稿，保存日方案回父页保留名称/顺序/合理滚动。保存失败不关闭，busy防重；挂起/退出释放footer和所属监听。原管理器复制/编辑/归档/永久删除/周期入口继续使用原路径。

常规视口的Save固定在所属footer。横屏、200%字体与键盘叠加造成正文无法容纳完整输入框时，同一个footer移入原modal-body随正文滚动；不增加第二滚动区。仅监听已有fitlog-viewport-change生命周期，根据实际框体可用高度决定位置，键盘关闭后恢复固定footer。实测输入框上下边界和滚动后Save完整可见，避免只检查键盘下边界而漏掉标题遮挡。日方案标题在原Back目标设置后恢复为真实添加/编辑标题。

从目标选择器进入原管理流程，保存或启用后返回时必须重新读取数据库，显示新模板和真实有效状态，并恢复有效列表滚动。该只读刷新使用现有route resume生命周期，在异步读取后注册回调，避免恢复回调Set迭代期间同步重注册导致重入；不引入全局监听或业务写入。

## 原型差异与验证

原型是假数据/假键盘，不移植其JavaScript、模拟日期或保存状态。正式使用项目token/标准控件、真实日期/四项值和已有单列营养字段，而不是假设备框；large框最高820px依现有共享Sheet，不硬编码演示720px。手动目标保留原编辑/删除表单；历史目标不随定义改变而重算。

[执行QA](NUTRITION_GOAL_TEMPLATE_V02_QA.md)和最终回执分开记录本地、正式部署、真实设备。浏览器键盘/Safe Area模拟不是实体iPhone证据；原安装PWA、VoiceOver、真实键盘/Safe Area与个人数据连续性无证据时Pending。保留原WebKit Undo −128px已知边界，不归为本轮解决。
