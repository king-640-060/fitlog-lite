- `CODEX_TASK.md`：唯一正式 Codex 实施指令；涵盖 A/B/C/D 与两项进度页视觉修复。
- `ACCEPTANCE_MATRIX.md`：逐项实际验收场景和证据矩阵。
- `prototypes/`：四份**原始、独立、可点击 HTML 原型**，不得覆盖修改。
- `previews/`：各原型截图，便于交叉检查布局和状态。
- `references/`：用户提供的真实界面截图，作为问题定位参考，而不是数据真值。
- `SHA256SUMS.txt`：原型/指令/素材文件校验表。
- `MANIFEST.json`：机器可读取的文件表与基线说明。
