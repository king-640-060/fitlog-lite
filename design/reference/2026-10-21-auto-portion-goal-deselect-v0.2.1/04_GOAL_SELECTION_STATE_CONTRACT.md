# 营养模板选中与生效阶段的边界

## 三个必须分离的状态

1. `selectedTemplateId`：只存在于当前 `设置目标` Sheet 的**内存 UI 草稿**，由用户点击决定，点同一模板再次归零。关闭再开可归零；**0 Dexie 写入**。
2. `NutritionStrategyPhase`：真正的“模板使用阶段”，与开始／结束日期相关，可覆盖当前日期。只由既有明确确认的启用/结束接口修改。**取消选中 UI 不结束阶段**。
3. `NutritionTarget`：某个日期的已保存营养目标快照，可能来源于手动、策略或营养周期。**删除当天目标不等于结束使用阶段**；再次打开选择器不因此生成选中态。

## 必测状态流

- 当前有生效阶段（模板 V1），今天已保存目标被日历删除 → 打开入口：显示「今天尚未设置目标」，V1 有阶段说明，但右侧圆圈**未选中**。
- 点 V1 → `aria-pressed=true`、20px 圆心填充、可继续选方案；再次点 V1 → `aria-pressed=false`，禁用继续按钮；其他 Phase/Targets/Logs 数据字节不变。
- 选 V1 → 选 V2：本轮草稿变成 V2，但不结束 V1 阶段、不启用 V2；如继续按现有流程提示是否启用，确认后按原日期合同处理。
- 已有当天 NutritionTarget 的情形：保存目标的来源、日期和数值仍单独显示，不用“当前阶段名”覆盖显示，也不凭数值相等推断来源。仅在用户明确点击应用目标后，用原事务保存/替换该日期目标。
- 关闭/取消 Sheet → UI 草稿丢弃，数据库完全不变；未启动阶段的历史资料不受影响。

## 不属于本轮的功能

不增加结束使用、调整开始/结束日期、归档/删除模板、按区间删除健康事实、营养周期排程改动。现有管理器中“结束当前阶段”功能保持原路径原规则；不在此选择页偷偷调用。**“取消选择”不是“取消使用阶段”。**

## 可访问性

模板行本身是 button（或等效真正可操作控件），`aria-pressed` 显式反映当前草稿选择；选择态不能只靠颜色，须有文字/语义。右侧 20px 圆圈只是可视指示器，不要求用户精准点击它；整行命中范围至少 44px，高缩放时圆圈和文本不可重叠、不可裁切。
