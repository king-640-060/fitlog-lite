# FitLog Lite — v0.4 已批准设计开发交付包

**用途**：用户将此 ZIP 作为一个附件发给 Codex。包内有不可修改的批准原型、真机问题截图、实施范围、验收矩阵、数据兼容与发布规则。**这不是生产代码，也不代表已经开发或部署。**

## 第一件事

1. 解压后先读本文件、`CODEX_TASK.md`、`DESIGN_LOCK.md`、`ACCEPTANCE_MATRIX.md`、`SAFETY_RELEASE.md`。
2. 运行 `sha256sum -c SHA256SUMS.txt` 或等价 SHA256 检查，结果必须全部通过。不要重新导出/改写原型以“修正”哈希。
3. 在浏览器实际打开 `prototype/FitLog_FoodTemplate_Water_DayDetail_v0.4.html`，操作四个页面，并对照 `screenshots/approved/`。所有截图是辅助，**HTML v0.4 的原字节为唯一权威视觉/交互原型**。
4. 实际读取仓库 `AGENTS.md`、`LATEST_DEV_REPORT.md`、`docs/CHAT_CODEX_WORKFLOW.md` 与任务涉及的现行设计、数据保护合同。检查当前远程 `main` 和工作区；不能把本文的起点当作永远不变。
5. **按 `CODEX_TASK.md` 完成开发与发布**，逐条回填 `ACCEPTANCE_MATRIX.md`，提供十项正式回执和可复核的测试/视觉/上线证据。

## 确认范围

- F1：饮食模板中食物重量的 `100g` 显示/输入布局核查与修复；不猜测真实克数。
- F2：可选创建「整日饮食模板」，每条食物关联早餐/午餐/晚餐/加餐；旧组合模板完全兼容。
- F3：饮水两枚等权快捷按钮 `+500 ml`、`+1000 ml`，低强调「自定义饮水量」；入口样式一致。
- F4：日期详情十类双列卡片保留铺满宽度，只压缩高度至批准的约 73px，记录增加后不变形；概览移除冗余说明，详情保留完整事实。
- F5：营养模板管理允许**无实际引用**的模板永久删除；有阶段/周期/已保存目标等引用的模板保护或归档；饮食模板已有删除入口要更易发现。

**不在范围内**：原 A–D、B1–B9 的重复实现；周期报告重写、外观系统重做、全局日历重排、训练业务或数据的大规模重构。不得擅自把饮食计划当成实际摄入。
