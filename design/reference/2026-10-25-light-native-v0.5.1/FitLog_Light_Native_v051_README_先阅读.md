1. 打开 `FitLog_Light_Native_v051_CopyAudit_20261025.html`；左侧切换 `Light Native / Original`，手机内五 Tab、右上 `···`、训练弹层可直接操作。
2. 切换 `有内容 / 无记录`：只审查今日饮食与力量训练两处的文案逻辑演示；其他页面也已经清除了明显的常驻介绍，但尚不能代替真实业务状态全矩阵。
3. 在原型侧栏选择 `320px`、`文字放大 200%`，查看数值、按钮和长文字。测试弹窗可在左侧“弹窗动效检查”里直接打开。
4. 阅读 `COPY_AUDIT_RULES.md` 了解不得误删的风险提示与业务信息。
5. 将 `CODEX_正式实施指令.md` 与本完整 ZIP 交给 Codex；以 `FitLog_Light_Native_v05_PREVIEW_20261024.html` 作为此前认可的视觉基准，以 v0.5.1 作为补充文案审查基准。开发前必须检查 GitHub 最新主干。
