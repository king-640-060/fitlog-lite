## 冻结范围及优先级

用户已确认：**v0.4 短距离上移 58px / 约275ms 的大 Sheet 入场 + 背景渐显 + 自然退出**；三种初始训练弹层采用同高 Large Sheet，力量和凯格尔执行界面维持既有独立形态。底部 Tab 固定五项：**今日 → 计划 → 饮食 → 训练 → 进度**，点击或横向拖动真正跟手；饮食日期轨及日期内容作为第二个独立横向滑动层，不引发主 Tab 切换。

现有项目代码与**数据保护合同**对业务/存储/无障碍始终有效。新批准的交互**仅在明确冲突的范围内**更新旧 `docs/UI_INTERACTION_SPEC.md`：“饮食内容不左右滑动切日 / 内容不做页面滑动过渡”的旧规则由本轮“饮食日期轨与日期内容联动跟手切换”所替代；日期本地语义、记录快照、iOS 边缘返回、原生纵向滚动和权限边界均不得改变。

原型不含真实业务数据。原型侧栏有一处旧装饰字样 `Interactive prototype · v0.3`，**它不是冻结版本号**；真实冻结文件以页面 `<title>` 中的 `v0.4`、本清单和 SHA256 为准。此轻微文案差异无需更改批准原型的原始字节。
