# 用户已批准的行为与实现边界 · v0.4

用户确认的最新原型版本是 `v0.4`，**并要求交付一个联合实现 ZIP**。当前没有授权更改其它功能。以同包 HTML 的互动手感为视觉锚点，以真实代码和数据合同为生产事实源。

## 主底部导航（第一项）

- 五个 Tab 永远是 **今日／计划／饮食／训练／进度**。原高度、图标20px、文字、固定底部、安全区和浅深色不变。
- 正选状态为柔和浅绿独立胶囊，深橄榄图标/文字（文字适度加粗）；非选中状态透明、灰绿色；所有状态图标/文字几何相同，无抬高、跳动或缩放。正确 `aria-current="page"` 或对应语义，当前状态不只靠颜色。
- 水平拖动**按手指实时**移动正在看的页面，同时呈现相邻页面；胶囊位置以同一连续进度插值。松手按速度/位移决定一次邻页切换或回弹。边界不可超过第一/最后页。不能仅在 release 后虚构滑动。
- 点击任意目标 Tab 直接切换，运动与胶囊协调，不需要经过中间 Tab 的业务渲染。快速连点以最后一次为准，点击当前页不重播动画。纵向滚动、斜向滑动、小范围触碰不应误导航。
- 系统侧边返回操作、文本选择/编辑、可点击控件和 modal 的语义优先。

## 饮食日期导航（第二项）

- 顶部日期导航维持原项目真实视觉：居中日期字、左右淡出、底部短绿色线；**不是**五个 Tab 的浅绿胶囊。
- 日期轨自身和下方饮食记录卡片**非交互空白区域**可以横向真正跟手切前后日期；日期轨与当天内容同方向连续移动、邻日内容逐渐出现，结束时吸附/回弹。点击轨上一个日期同样切换。
- 滑日期不切底部主 Tab；滑主 Tab 时不更改当前饮食日期。不得在一天的数据尚未确认时错误显示另一天的卡路里或汇总；真实 FoodLog、目标和餐次必须按所选 device-local 日期读取。
- 保留向远日日期选择器跳转、回到今天、自然纵向滚动、记录编辑/Sheet 原事件生命周期、日期滑轨惯性及焦点/无障碍。若 native scroll snap 与自定义日期页面联动技术上冲突，需拿出真实 Safari/WebKit 触摸验证而非放弃跟手效果，或停止该点请求用户确认。
- 本项是对 `docs/UI_INTERACTION_SPEC.md` 旧版“Food body 不切日/内容不滑动过渡”规则的**明确例外及更新**；不是准许全局替换所有横向内容。

## 三种训练大 Sheet（第三项）

- 点击开始力量的**初始选择**弹层、记录有氧的表单、凯格尔的**方案选择**，都使用现有 Large Sheet 外框尺寸 `min(820px, 可用视口−12px)`，同一设备同一键盘状态的顶部对齐。内容留在各自内滚，不强制同内容、同按钮数。
- **不会**将已经记录中的力量训练执行页变成 Sheet；**不会**将凯格尔沉浸式计时界面变成 Sheet；有氧业务表单、保存、编辑、错误保留原状。
- v0.4 进一步批准进入视觉：从下方约58px短距离上移、约275ms自然减速，遮罩约210ms渐显，轻柔退出。使用 CSS transform/opacity；无整屏长滑、弹簧、跳动、缩放或模糊；支持系统 Reduce Motion。时长是手感基准，可因真实键盘/物理手势微调，但不得重新变成瞬间跳出。
- Sheet 关闭、替换、确认子弹层、Back、点击遮罩、Esc、键盘开闭、VisualViewport、Safe Area、焦点恢复需保留原共享生命周期。不允许因异步出口动画让业务清理通知重复或延迟至丢数据。

## 额外不变项

- 进度页体重、饮水、睡眠趋势图30/90天原生水平滚动（及7天如适用）、日历月份/日期操作都独占各自事件。
- 表单输入和训练草稿不随误触/导航静默丢失；计时/自动保存/音频/未完成训练状态不静默重建、重置或结束。
- 无数据结构/导入/恢复/Sync/AI/隐私/PWA机制调整。保留历史的真实时间/日期与记录快照，不能让视觉位置驱动写事务。

## 不要误把原型当生产业务

HTML 与 MP4 **仅为视觉交互参照**，原型的食物热量、历史、训练模板、按钮标签等演示事实不得进入业务库。示例视频来自不同产品，它的主题/图标不可复制。最终应使用 FitLog 当前真实应用的组件、文案、数据与入口。
