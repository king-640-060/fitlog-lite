# 手势、过渡、异步、Sheet 与训练状态协调合同

这个文件用于避免“动画看起来完成了，但真实 App 切错页、吞手势、丢草稿或抢键盘”的实现。原型是验收视觉依据；**生产手势需适配真实长内容/复杂异步渲染，不允许直接复制原型模拟 DOM**。

## 1. 事件归属优先级（高到低）

1. iOS 系统左侧返回手势、系统文本选区/编辑状态、原生滚动与无障碍操作。不要在屏幕左 edge 执行阻断全局系统手势的 `preventDefault()`；边缘宽度要在物理 iPhone 上确认。
2. 已打开的 Sheet/dialog 或沉浸式训练、键盘输入、控件/表单草稿、抽屉/确认界面。Sheet 打开期间主 Tab 和日期内容横向拖动**不响应**。系统键盘激活后遵循现有视觉视口/导航隐藏策略。
3. 有明确独占横向需求的内部组件：饮食日期轨、饮食记录的用户批准手势空白区域、体重/饮水/睡眠趋势图的 scroll owner、可能的横向选择列表、日历月份导航。拥有者一旦识别，父级主导航不得共同响应。
4. 主页面空白横向区域，且手势满足水平距离优于垂直距离、最小位移和有效速度条件，才可占用主 Tab。
5. 垂直或斜向不明确手势交还自然滚动；不能全局 `touch-action:none`、不能劫持整页 touchmove 或普遍禁用 `user-select`。

**事件实现建议（非强制）：** 以 pointer/touch 坐标计算一次手势会话 `owner / startX/Y / lastX / velocity / activeIndex / transitionId`；先锁方向，再仅在合法本地 surface 调整 `transform: translate3d`。浏览器 touch pointer capture 丢失时防止误取消/二次结束。阻断导航通过检查 openDialog/keyboard/editor/immersive；不通过重写主 App 数据状态控制动画。

## 2. 主导航单一事实源

- 维护一个真实 `activeTab`；动画可维护 `fromTab / toTab / progress` 的展示性中间态，但**禁止在拖动中**写业务库或把临时目标当成功完成。
- 只允许相邻页手势目标；任意 Tab 点击是指定目标的**直接**语义跳转。期间新点击应更新到最新目标，取消/替换旧 tween；不得出现在页面 A、胶囊 B、aria C 三者不一致的稳定状态。
- 一次 commit 定义最终激活的 tab、`aria-current`、焦点语义与胶囊最终位置；回弹时恢复此前 active 而不二次业务渲染。点击已选 Tab 不触发新的整页入场。
- 为真实相邻页面准备绘制内容后才开放交互，拖动途中呈现邻页，不能“滑动时候空白、松手才渲染”。可用有限预挂载/预计算/受控片段缓存，**但不能凭缓存复用过时业务事实、破坏 IndexedDB liveQuery 清理或复制未保存表单**。严禁为五页动画批量触发副作用/数据迁移。
- 异步渲染必须受代次 token / AbortController / request revision 守卫约束。慢页面 A 完成后，不能覆盖用户已跳到 B 的内容或重置胶囊。
- **草稿归属**：不要凭导航就清空没有明确“关闭/放弃”操作的输入；现有 WorkoutAutosave、plan/food draft、Sheet 内明确提交保留原生命周期和业务写保护。反向快速拖动、刷新 UI、重开弹层都需测试。

## 3. 饮食日期导航的内外两层

- 独立 foodDate 与 foodGestureState；不是底部 Tab 目标。`shiftLocalDate` / device-local `YYYY-MM-DD` 保证夏令时/月末/年末正确，不通过 UTC 时间戳切日。
- 拖动期间可以预览邻日的只读内容和顶部中间运动，但**不可把预览改成已确认的 FoodLog 数据**, 不按中间 progress 写数据库。提交日期时，顶部 `aria-current="date"`、日期标题、营养汇总、餐次、FoodLog、目标全部来自同一已选 `foodDate`。
- 日期内容滑动仅发生在用户批准的顶部日期或内容空白手势区，不能夺走 FoodLog 记录行按钮、日期选择器、餐次菜单、横向芯片/输入。触摸事件通过 owner 决定，父导航不触发。
- 使用当前 `foodPager` 保留可见日期窗居中、点击日期、异步请求过期过滤、`foodRailNeedsRecenter` 近边再窗口重置与已选按钮 focus；不能为一次轻微滚动重建全部食品 DOM 或导致列表滚动到顶部。
- iOS native 横向惯性对已有日期轨很重要。若需要在 native 日期轨之上协调下方内容 transform，建立受控 scroll-progress 映射而不是未经测试废掉惯性和滚动末尾吸附。**已批准行为是跟手的日期内容联动，具体底层 scroll/pointer 机制可选择与实际 iPhone 兼容者**。

## 4. Chart / Calendar / Sheet 的事件优先

- 趋势图滚动（30/90天）必须维持图自身滚动偏移且 activeTab/foodDate 不变；点击数据点、键盘左右选择照旧。Calendar 点日期/换月份照旧。
- Sheet 打开后根导航禁用交互，但页面幕后状态保留；关闭后恢复原 scroll/焦点/原始表单状态（除非用户明确提交/退出）。
- 当前 `presentDialog()` 关闭语义有**同步一次性** close 通知与 ref-counted background scroll lock。引入关场动画要避免 `setTimeout` 造成 `close` 事件重复、body lock 早解/晚解、Focus 反跳、替换时遮罩盖住新 Sheet；允许退出视觉与业务同步通知解耦，但只在合同内完成，必要时增加时序测试。
- `VisualViewport` 是共享唯一事件源，不在三个训练入口分别安装全局 resize/keyboard/listener。输入激活时，Sheet 能在可视区域内滚动、保存和返回按钮可见，键盘下降后恢复一致。
- `body.immersive` 与凯格尔计时页不可被导航动画或全局 Sheet 动画遮盖；定时器的 pause/stop/wakelock/音频主动操作保持原行为。

## 5. 动效预算与竞争条件

- 与冻结原型协调：底部主导航/日期释放自然减速约200–280ms，速度门槛依据真实手感校准；胶囊与页面相同进度。大 Sheet 进场约58px/275ms、遮罩约210ms，退出自然协调。严格是**原型手感参考**而非鼓励盲目定时器。
- 只对 `transform/opacity` 逐帧写入，避免动画帧改变 width/height/left/top/reflow；不要新增重复 `requestAnimationFrame`、scroll listener 或未清理 observers。
- `prefers-reduced-motion` 从启动时生效，且运行中改变时能撤销/快速完成动画并维持一个确定最终态。长动效不能阻碍点击和语音/键盘操作。
- `pagehide`、拖动中途旋转/resize、Sheet 弹出/退出、连续快速点 5 Tab、浏览器后退、键盘弹出，应全部取消旧动画并保留正确 final activeTab。严禁闪屏/空白/幽灵 overlay/重复保存。

## 6. 可测的核心不变量

| 不变量 | 如何核实 |
|---|---|
| 拖动中真实位移 | 真实 pointer/touch 注入中间帧，页面和胶囊 `DOMRect`/transform 随 dx 变化，邻页可见 |
| 不扰动业务 | 同一合成旧数据 profile 全22-store只读哈希及8-config一致，未触发保存服务 |
| 食物日期与主 Tab 独立 | 日期手势后 `foodDate` 变、activeTab 仍 food；主 Tab 手势后 foodDate 不变 |
| Chart 内部优先 | 图 scrollLeft 改变，主 Tab 与 foodDate 不变 |
| Sheet 统一 | 三类 Sheet 同宽同视口同字体下 outer Rect top/height 相等，长内容内部能滚到底 |
| Sheet 生命周期 | 开关/替换/内部跳转 close 回调次数=1，无多余 body lock，focus 合理恢复 |
| Workout/Pelvic 连续性 | 未完成 Workout ID/sets/autosave 未丢；Pelvic running state/计时不因主页面导航隐式清除 |
| 无障碍 | `aria-current` 单一正确；Reduce Motion、44px 热区、16px 编辑、键盘 focus 与缩放均正常 |
