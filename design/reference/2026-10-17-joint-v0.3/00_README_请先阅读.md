## 这次与上一轮的差异

1. 首页饮水：保留收起式 UI；「记录饮水」在**数值右侧**，和睡眠等卡片一致；标准 SVG 箭头对齐；展开／记录成功后**有条件自动滚动**保证操作区可见，不要每次数据库刷新都抢滚动位置。
2. 趋势：**体重、睡眠、饮水仍是三张独立图，每张各有自己的 7／30／90 天选择器**。只是日期标签统一：7 天逐日全部显示，30／90 天逐日占位并允许横向滚动；未记录保留日期，不填0。最关键：**无论切换 7／30／90 天，同一个趋势模块的整卡、图表、SVG/Canvas 绘图区、日期轴、控制区的高度必须严格一致**，全无睡眠也一样。纵轴视觉缩放不因切换产生突然大幅跳变；遵守批准原型的统一90日参考域。
3. 报告：取消 `综合／力量／增肌／减脂` 四种阅读焦点；只保留**日常综合报告**、**营养周期报告**两种入口。报告提供教练可用的营养/训练/体重/饮水/睡眠分析、覆盖率、谨慎且可追溯建议；**不引入普通任务**。
4. 模板删除：这是对上轮「仅六类数据级联」的**明确扩大**。删除某营养模板时，删除原六类模板归属对象**加上该模板全部使用阶段/营养周期日期并集内的每日健康事实**，**计划模块任务与标签、日期区间外事实、跨日期复用的资料模板定义一律保留**。先有范围及精确计数预览，勾选风险 + 第二次确认，在统一原子事务内写入，失败整体回滚。此范围可能包含与模板没有物理外键关系但发生于日期区间内的健康事实，必须明确告诉用户。
