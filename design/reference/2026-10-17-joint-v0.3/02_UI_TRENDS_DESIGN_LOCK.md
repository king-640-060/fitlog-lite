# 设计锁：Today 饮水 + 三张独立逐日趋势（v0.3 批准）

## Today 收起饮水卡

- 与旁边「睡眠」等卡片**相同满宽/边距/圆角/结构**；标题、历史记录在同一顶行。累计数值在左，「记录饮水」**在内容右侧**，不是整行放在最下面。
- 箭头用统一的 `chevron` SVG，不用偏位文本字形 `⌄`。与文字使用 flex `align-items:center`、固定图标 viewBox/stroke、可旋转 180 度、aria-expanded 与 aria-controls/hidden 始终一致。
- 默认收起；展开后 `+500 ml`、`+1000 ml` 两个等权按钮以及低强调「自定义饮水量」，无无意义巨大的左右留白。Progress 水记录 Sheet 保持上一轮已批准的紧凑外观，**不在此次反向扩大**。
- 展开时布局完成后计算操作区域 bounding rect 与真实 PWA 滚动容器、底栏及 safe-area 的可视区；**只在必要时滚动到完整可见**，尊重 prefers-reduced-motion。成功记录后延续展开，必要时再定位；数据 liveQuery 和设备参考值更新不自动抢滚动位置；失败不加水，忙碌防双次写。取消自定义、Undo、编辑/删除历史均保留。避免使用死板 `window.scrollBy` 当真实 PWA 使用了内部滚动层。
- 已批准原型演示是“右侧按钮+展开时可见”，不是生产组件源代码。320/375/390/430 iPhone、缩放100/140/200%、深浅、横屏、动态安全区与下导航均要视觉对比，触控 >=44px，字号保持可读。

## 趋势图：不是拼图、共享控制，也不是日期取样

- 三张各自独立：**体重／睡眠／饮水**，独立 7/30/90 range state、选中日期、水平滚动和真实值读数。
- 三者底部日期轴都以连续自然日产生：7天显示所有7天（跨月有月标识）；30/90保留每天的位置并允许横向滚动，而不是把90天硬压成一屏。未记录仍有日期轴格位，**空≠0**；无完整睡眠记录仍显示空日历轴且高度不变。
- 体重只在真实日期绘制事实点；不把缺失日当0，也不把插值点伪装为测量点。如仍以线段连接点，需清楚说明线段非实际测量；可选更保守断线方式，用户原型允许空白标识。
- 睡眠按 `resolveSleepBusinessDate`/所属夜晚归属，不按起床日再算一天；active session 不充当已完成睡眠。饮水按日志的用户本地业务日期，准确聚合多条记录。体重同日多条记录继续采用项目现有去重/选择口径，禁止破坏历史记录和编辑功能。

## 不可妥协的 7/30/90 不变高合同

- 每一图在任一当前数据集、任何同一视口/文字缩放/主题：逐次点击 **7→30→90→7**，以下 bounding boxes 高度均应相同（建议容忍 subpixel `<0.5px`，稳健四舍五入）；**整张趋势卡、标题、图表滚动容器、SVG/Canvas绘图区、日期标签轴、日期范围切换行、记录覆盖提示、底部帮助文字**。不允许90天曲线 SVG viewBox 比7天高、90天增加额外换行、状态空白时整块消失。
- 测试 `height(7)===height(30)===height(90)`，不能只测 `scrollWidth` 或卡片宽度；不许只给外层 min-height 掩盖内图尺寸变化。字体从100→200%的**不同字号之间允许整体变高**，但**同一字号中三种范围绝对不变高**。
- 纵向 Y 刻度使用相对一致的参考域（批准原型以最近90天真实数据确定域，切换range只裁切横向日期）；某一天实际值在7/30/90中只要可见，其纵向位置应基本稳定。对异常大值、无数据/单点、主题切换做单独健壮性测试，不能造虚假的数值。
- 生产真实图表的 X 轴日期 font 建议保持约12–13px可读，字体缩放遵循全局设置；在320px一屏如果有拥挤，应优先选择简短的日号、跨月月份标示、内部可滚动布局，不能静默改成隔日日期。

**已批准 QA 测量摘要**（来自内存原型；不等于正式应用验证）：390px 浅色，体重卡 364.09px、图表滚动 184px、图形150px、日期轴31px，在 7/30/90 完全一致。细表见 `reference_qa/measured_heights_v0.3.json`，包含 320/375/390/430 × light/dark × weight/sleep/water 的数值测量与无睡眠验证状态。**140/200% 字体压力不包含在此 JSON 的逐项原始高度记录中**，Codex 必须另行实测并归档结果；不能写死这些像素来冒充一致性。
